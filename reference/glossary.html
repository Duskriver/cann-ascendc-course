CANN & 达芬奇架构核心术语表

按需查阅的课程词汇表。第一课重点关注 CPU/NPU 分工及向量加法数据流，其余概念在后续课逐步展开。

💡 查阅准则： 遇到不熟悉的名称时再查阅，无需一次记住。以下描述以本课典型 Ascend C 向量编程模型为主，具体接口与硬件能力请结合目标芯片和 CANN 版本文档。
CANN 算子开发核心软硬件术语清单
术语 (中文 / 英文) 硬件 / 软件角色 核心定义与算子开发意义
Host 与 Device
主机与设备		 系统异构拓扑 Host 指主机 CPU 一侧，负责组织任务、准备数据并发起计算；Device 指昇腾 NPU 一侧，执行所分配的计算任务。主机内存与设备内存之间的传输，和 NPU 内部 GM 与 UB 之间的搬运是两个层次。
CANN
Compute Architecture for Neural Networks		 软件栈中间件 华为面向昇腾的异构计算软件栈，连接上层 AI 框架与底层硬件，提供编译、运行时、算子库及开发工具。本课先将它理解为组织和执行 NPU 任务的软件支持。
AI Core
达芬奇计算核心		 硬件执行单元 昇腾 NPU 的计算核心。本课程用 Vector（向量）、Cube（矩阵）和 Scalar（标量）说明计算与控制分工；不同芯片的单元组织方式和存储配置有所不同，具体以目标型号文档为准。
Cube 单元
矩阵乘加速器		 AI Core 计算部件 用于矩阵乘加的硬件单元。例如将 M × K 的矩阵与 K × N 的矩阵相乘，得到 M × N 的结果。支持的分块形状、数据类型和吞吐能力依芯片型号而定；第一课作为选读。
Vector 单元
向量计算部件		 AI Core 计算部件 用于对一批数据执行向量计算，可组合实现元素级运算、激活和归一化等算子。本课的向量加法先把输入搬入 UB，再调用计算接口；这不表示只能处理一维形状的张量。
Scalar 单元
标量计算部件		 AI Core 控制部件 负责标量计算和流程控制，例如循环计数、地址计算与条件分支。第一课只需认识它承担控制工作，不要求掌握其指令细节。
Global Memory (GM)
全局显存 / HBM / DDR		 片外大容量存储 设备侧的全局内存，位于计算核心之外，用于存放输入输出等数据。物理存储介质可为 HBM 或 DDR，容量依设备型号而定。本课的向量计算接口使用 UB 中的数据，因此先将输入从 GM 搬入 UB。
Unified Buffer (UB)
统一缓冲区		 片上高速 SRAM 存储 用于向量计算的片上高速暂存空间，容量依芯片型号而定。在本课的向量加法中，输入先从 GM 搬入 UB，计算结果也先留在 UB，再写回 GM。它不是主机内存，也不等同于 CPU 自动管理的缓存。
L1 / L0
矩阵计算相关片上存储（选读）		 片上存储层级 矩阵计算相关的片上存储层级，用来暂存输入与中间结果；L0 常按输入或累加结果分为 L0A、L0B、L0C。具体数据通路和容量依芯片型号而定，留待矩阵算子课程展开。
MTE (Memory Transfer Engine)
片上搬运引擎		 硬件 DMA 控制器 负责不同存储位置之间数据搬运的硬件引擎。本课用 MTE2 表示 GM → UB 的搬入、MTE3 表示 UB → GM 的写回。搬运与计算可以重叠，但需要正确安排缓冲与同步；具体通路依芯片型号而定。
Ascend C
昇腾 C/C++ 算子编程语言		 编程接口规范 用于昇腾算子开发的 C/C++ 编程语言与接口体系。本课程从向量编程范式入门，通过搬运、计算、内存管理与同步接口组织核函数；不把一种范式视为所有设备和算子的唯一写法。
Tiling
数据分块切片		 Host 侧调度策略 根据数据形状和硬件资源制定切分策略，包括多核任务分配和核内分块。每个核可在一次核函数执行中循环处理多个数据块；第一课先理解“工作台有限，需要分批处理”。
TPipe & TQue
管道与消息队列		 Ascend C 基础管道抽象 Ascend C 流水编程范式中的资源和队列管理接口。TPipe 管理相关资源，TQue 用于阶段间的数据传递与同步。开发者仍需正确安排入队、出队、缓冲分配与释放；实现重叠还取决于缓冲配置和数据依赖。
