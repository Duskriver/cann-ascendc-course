CANN & 达芬奇架构核心术语表

算子开发与底层硬件协同的标准化词汇基准，所有课程均严格遵从本表定义。

💡 查阅准则： 异构计算学习中最容易造成记忆混淆的是各类存储（GM、UB、L1/L0）和搬运引擎（MTE）。每当遇到不熟悉的硬件缩写，随时回到本表速查。
术语 (中文 / 英文) 硬件 / 软件角色 核心定义与算子开发意义
Host 与 Device
主机与设备		 系统异构拓扑 Host 指运行通用操作系统（Linux）的主机 CPU，负责任务分发与流程控制；Device 指昇腾 NPU 硬件加速器，负责执行高密度并行计算。
CANN
Compute Architecture for Neural Networks		 软件栈中间件 华为异构计算架构，向下屏蔽昇腾芯片硬件细节，向上支撑 MindSpore、PyTorch、TensorFlow 等 AI 框架，提供驱动、Runtime、图引擎（GE）与统一算子库。
AI Core
达芬奇计算核心		 硬件执行单元 昇腾 NPU 的核心计算引擎，内部集成了 Cube（矩阵）、Vector（向量）、Scalar（标量）三大计算单元及多级片上高速缓存。
Cube 单元
矩阵乘加速器		 AI Core 计算部件 专用于大颗粒度矩阵乘法（$M \times K \times N$）硬件加速，单指令即可完成三维立方矩阵乘加运算，是大模型计算的主力。
Vector 单元
向量计算部件		 AI Core 计算部件 专用于一维数组/张量的并行运算，负责元素级加减乘除、激活函数（ReLU/GeLU/Sigmoid）、归一化（LayerNorm/Softmax）等操作。
Scalar 单元
标量计算部件		 AI Core 控制部件 执行常规基础控制流指令（循环计数、地址计算、分支跳转），相当于 AI Core 内部的微型控制大脑。
Global Memory (GM)
全局显存 / HBM / DDR		 片外大容量存储 位于 AI Core 之外的高容量内存（数十 GB）。容量大但访问延迟较高，AI Core 的计算单元无法直接在此处进行数学运算。
Unified Buffer (UB)
统一缓冲区		 片上高速 SRAM 存储 AI Core 内部专供 Vector 单元读写的高速片上暂存空间（通常几百 KB）。数据必须由 GM 搬入 UB 才能被 Vector 单元计算。
MTE (Memory Transfer Engine)
片上搬运引擎		 硬件 DMA 控制器 负责不同存储介质间（如 GM ↔ UB、GM ↔ L1/L0）异步数据搬运的专用硬件管线，实现数据搬运与数学计算的流水线重叠。
Ascend C
昇腾 C/C++ 算子编程语言		 编程接口规范 原生 C/C++ 风格的高性能算子开发语言，采用 SPMD（单程序多数据）编程模型，提供自动多级流水调度与丰富的结构化 Tensor API。
Tiling
数据分块切片		 Host 侧调度策略 将全局显存中超出片上高速缓冲区（UB）容量的超大 Tensor，切分为若干适合单次核函数与单块缓存处理的瓦片（Tile）的数学算法。
TPipe & TQue
管道与消息队列		 Ascend C 基础管道抽象 Ascend C 提供的片上数据流管理机制。开发者通过队列在 `CopyIn`、`Compute`、`CopyOut` 之间传递临时缓存指针，硬件自动完成同步与乱序隐藏。
