# 学习者起点与实操环境基线

学习者目前处于**异构计算零基础**状态，没有预设的 CUDA/GPU 编程背景，因此教学中不能直接用“就像 CUDA 的 Shared Memory / Warp”来解释概念，而必须从 CPU 与 NPU 的分工对比、车间流水线与高速缓存的直观模型出发。同时，学习者**手头拥有真实的昇腾硬件环境**，每节课除了浏览器内的交互式检索练习外，都可以设计 1 个轻量、可立即在昇腾终端验证的命令或代码片段，实现“概念理解 -> 浏览器交互反馈 -> 真机验证”的闭环。

## Implications
- 禁止在未解释的情况下堆砌缩写词（AI Core、GM、UB、L1、Cube、Vector、Tiling、Pipe、Queue 必须在 `reference/glossary.html` 中统一定义并在课程中循序渐进引入）。
- 第一课（Lesson 0001）必须先帮学习者建立**异构计算（Host + Device）**与**达芬奇 AI Core 内部三大计算单元 + 三级搬运流水线**的心智模型，并引导其在昇腾机器上执行第一次硬件探针命令。
